# 🤖 Machine Learning Study

> **ChatGPT의 도움을 받아 머신러닝을 체계적으로 학습하고, 직접 구현하며 이해한 내용을 기록하는 개인 학습 저장소입니다.**

## 📌 프로젝트 소개

이 저장소는 머신러닝의 기초 개념부터 주요 알고리즘, 모델 평가 및 실전 프로젝트까지 단계적으로 학습하기 위한 공간입니다.

**ChatGPT를 AI 학습 도우미로 활용**해 개념 설명, 실습 문제, 코드 리뷰, 오답 분석에 도움을 받습니다. 단순히 AI가 생성한 코드를 복사하는 대신 **직접 구현하고, 결과를 해석하고, 왜 그렇게 동작하는지 이해하는 것**을 목표로 합니다.

## 🗺️ 전체 학습 커리큘럼

| 단계 | 학습 주제                     | 주요 내용                                                                                          |
| ---- | ----------------------------- | -------------------------------------------------------------------------------------------------- |
| 01   | Machine Learning Fundamentals | 머신러닝 개요, 학습 흐름, Feature/Target, 지도·비지도학습, 분류·회귀, 데이터 분할, 과적합·과소적합 |
| 02   | K-Nearest Neighbors (KNN)     | 최근접 이웃, 거리 계산, KNN 분류·회귀, K값과 스케일링                                              |
| 03   | Decision Tree                 | 의사결정나무 원리, Gini·Entropy, 분류·회귀, 하이퍼파라미터                                         |
| 04   | Random Forest                 | 앙상블, 배깅, 분류·회귀, Feature Importance                                                        |
| 05   | Model Evaluation              | 분류·회귀 평가 지표, 교차 검증, 모델 비교                                                          |
| 06   | Preprocessing & Pipeline      | 결측치 처리, 인코딩, Pipeline, 데이터 누수 방지                                                    |
| 07   | Future Topics                 | 심화 알고리즘 및 추가 학습 주제                                                                    |
| 08   | Projects                      | Iris 분류, 주택 가격 예측 등 종합 실습                                                             |

> 학습 순서와 세부 주제는 진행 과정에서 조정될 수 있습니다. 상세 학습 기록은 [`docs/learning_progress.md`](docs/learning_progress.md)에서 관리합니다.
